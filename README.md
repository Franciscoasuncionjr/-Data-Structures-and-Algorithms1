# Sorting Algorithms Activity

## Introduction

Kini nga Java program nagpakita kung giunsa pag-arrange sa mga numero gikan sa pinakagamay hangtod sa pinakadako. Gigamit niini ang tulo ka sorting algorithms: Bubble Sort, Selection Sort, ug Insertion Sort. Ang matag algorithm adunay kaugalingong pamaagi sa paghan-ay sa mga numero.

## 1. Bubble Sort

Ang Bubble Sort nagkumpara sa duha ka magtapad nga numero. Kung ang unang numero mas dako kaysa ikaduha, ilang ibaylo ang ilang posisyon. Padayon kini hangtod mahan-ay ang tanang numero gikan sa gamay ngadto sa dako.

## 2. Selection Sort

Ang Selection Sort mangita sa pinakagamay nga numero sa array. Human kini makit-an, ibutang kini sa unang posisyon. Dayon pangitaon napud ang sunod nga pinakagamay nga numero hangtod mahuman ang paghan-ay.

## 3. Insertion Sort

Ang Insertion Sort nagkuha og usa ka numero ug mangita sa sakto nga lugar niini. Ibalhin ang mga numero nga mas dako aron mahatagan og lugar ang numero nga gisulod. Padayon kini hangtod mahan-ay ang tanan.

## Differences Between the Three Sorting Algorithms

Ang Bubble Sort naggamit og pagkumpara sa magtapad nga mga numero. Ang Selection Sort mangita una sa pinakagamay nga numero. Ang Insertion Sort mosulod sa matag numero sa iyang sakto nga posisyon.

Lahi-lahi ilang pamaagi, apan pareho silang makahimo sa paghan-ay sa mga numero gikan sa pinakagamay hangtod sa pinakadako.

Ang Bubble Sort nagkumpara sa magtapad nga numero ug mag-ilis kung kinahanglan. Ang Selection Sort mangita sa pinakagamay nga numero ug ibutang kini sa sakto nga posisyon. Ang Insertion Sort magkuha og numero ug ibutang kini sa hustong lugar. Lahi ilang proseso apan pareho ang ilang resulta.

### 2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?

Para nako, ang Bubble Sort ang pinakasayon sabton ug buhaton kay simple ra ang proseso niini. Kinahanglan ra ikumpara ang duha ka magtapad nga numero ug mag-ilis sa ilang posisyon kung sayop ang pagkahan-ay.

### 3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.

Para nako, ang Insertion Sort ang mas maayo kung daan nang sorted ang mga numero. Dili na kaayo kini kinahanglan magbalhin-balhin sa mga numero kay naa na sila sa hustong posisyon.

### 4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?

Kung modaghan ang mga numero sa array, mas daghan ang ilang ikumpara ug i-arrange. Mahimong mas dugay ang paghuman sa tulo ka algorithms, labi na kung daghan kaayo ang mga numero.
